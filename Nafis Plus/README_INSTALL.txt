نافس بلس — نسخة قابلة للتثبيت دون متجر التطبيقات (PWA)

الملفات جاهزة للنشر على GitHub Pages أو أي استضافة HTTPS.
1. أنشئ مستودع GitHub عام (Public) باسم nafis-plus.
2. ارفع محتويات هذا المجلد إلى جذر المستودع: index.html و sw.js و pwa.js و manifest.webmanifest و icons و pdf، وبقية الملفات.
3. من Settings > Pages اختر Deploy from a branch، ثم main و /(root)، واضغط Save.
4. افتح https://YOUR-USERNAME.github.io/nafis-plus/ (استبدل اسم المستخدم).
5. Android: افتح الرابط في Chrome ثم اضغط تثبيت التطبيق (أو قائمة ⋮ > تثبيت التطبيق).
6. iPhone: افتح الرابط في Safari ثم مشاركة > إضافة إلى الشاشة الرئيسية > فتح كتطبيق > إضافة.
7. Windows: افتح الرابط في Chrome أو Edge ثم استخدم زر تثبيت التطبيق أو أيقونة التثبيت بالمتصفح.

ملاحظات مهمة:
- لا يمكن تثبيت PWA من ملف ZIP أو رابط file:// مباشرةً. يجب نشر الموقع عبر HTTPS أولًا.
- الصفحة والـ54 PDF تُخزَّن للتصفح بدون إنترنت بعد اكتمال تثبيت التخزين المؤقت عند فتح الموقع متصلاً.
- أسئلة التدريب غير رسمية؛ التصحيح آلي لدوائر التظليل وليس تصحيح إجابات نصية بالذكاء الاصطناعي.
- تُحفظ النتائج داخل الجهاز والمتصفح، وليست مشتركة بين هواتف المعلمين أو الكمبيوتر.
- إن حذفت بيانات المتصفح، قد تُحذف النتائج؛ صدِّرها CSV للحفظ.
- البحث عبر Google لا يظهر تلقائيًا بمجرد النشر؛ إضافة الموقع إلى بحث Google عملية منفصلة وقد تستغرق وقتًا.
- عند نشر تحديثات للملفات، غير قيمة VERSION في sw.js لفرض تحديث ملفات التخزين المؤقت.

تجربة الموقع محليًا على الكمبيوتر: شغّل خادم localhost أو افتح index.html للمعاينة. تثبيت التطبيق يتطلب localhost أو HTTPS.
