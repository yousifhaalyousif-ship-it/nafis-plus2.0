NAFIS Plus V9 — GITHUB PAGES EDITION
===================================
NO Cloudflare, NO Python, NO .bat file, NO school-account setup.

HOW TO PUBLISH
1. Open GitHub and open your existing app repository (or create a NEW PUBLIC repository).
2. Upload the CONTENTS of this extracted folder (not the ZIP itself).
   Important: index.html must be in repository ROOT, alongside online.js,
   online.css, data.js, paper.html, manifest.webmanifest, sw.js, install.js,
   AND the entire icons/ and pdf/ folders with their original structure.
3. In GitHub repository go Settings > Pages.
4. Under Build and deployment select Deploy from a branch.
5. Branch: main / Folder: /(root) > Save.
6. Open the HTTPS GitHub Pages URL after the deployment finishes.

INSTALL APP
- Tap the green "تثبيت التطبيق" button on the homepage.
- iPhone: Safari > Share icon > Add to Home Screen > Add.
- Android: Chrome menu > Install app or Add to Home Screen.
- Windows: Chrome / Edge > Install App (may be available in address bar).

TEACHER
1. Open the teacher section from the app.
2. Select subject and use the THREE EXISTING TEACHER PASSWORDS (from V7).
3. Select GRADE and MODEL, then generate a code and give it to students.
4. Students use the SAME GitHub Pages URL and that code.
5. At the end, students click Download Result (JSON) or Copy Result Code.
6. Students SEND the file/code to the teacher using their chosen channel.
7. Teacher selects Import files or pastes a result code in teacher dashboard.
8. Teacher can export a subject's results to CSV.

IMPORTANT LIMITS FOR GITHUB PAGES
GitHub Pages is only static hosting. It CANNOT securely collect or synchronize
results from different devices. A password in a static site is UI-level only,
not real access control, and results may be altered by someone using browser
tools. Thus this edition is for practice/demo use, not for confidential
student records or an official examination system. "Close room" only affects
that browser; codes remain usable elsewhere. The generated classroom code
contains grade/subject/model so it works across phones without a server.

All 54 PDFs are in /pdf and the original paper printing / scan-review
page is paper.html. Scanner accuracy depends on photo quality; double-check
answers before saving grades.

If you see the OLD website after uploading, try a hard refresh, clear site
cache or remove/reinstall the old home-screen shortcut.
